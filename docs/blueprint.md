# **App Name**: CellNexus

## Core Features:

- Intelligent Access Guard: Multi-tier authentication and Role-Based Access Control (RBAC) ensuring tailored visibility for Admin, Leader, and Member profiles.
- Member Lifecycle Engine: Comprehensive CRUD system to manage member fields including Name, Status, Ladder of Success, and Target To Do lists within the database.
- AI Growth Insights: A generative AI tool that analyzes a member's Ladder of Success and Target To Do history to suggest personalized next steps and coaching focus points.
- Unified Command Dashboard: Dedicated perspectives for each role: Admin views global telemetry, Leaders monitor assigned pods, and Members track personal growth milestones.
- Precision Analytics Hub: Live statistical readout displaying user counts and cell distribution through minimalist cards and interactive SVG charts.
- Dynamic Registry Tool: Advanced search and filtering system for quickly locating and updating specific member records across large datasets.
- Liquid Responsive Frame: An adaptable Next.js layout ensuring full functionality from widescreen admin desktops to high-mobility leader smartphones.

## Style Guidelines:

- Dark-mode palette inspired by machined aluminum: Primary color is a clean Off-White (#E5E7EB) for high readability.
- Background color is a deep Onyx Black (#111418), derived from a desaturated cool-blue hue to maintain a sleek, premium monochrome feel.
- Accent color: Muted Slate-Blue (#8FA0A3), used sparingly for interactive highlights and status indicators.
- Using 'Inter' sans-serif exclusively to maintain an objective, modern, and neutral appearance across dashboards and reports.
- Slim, linear icons (stroke weight: 1.5px) used for the sidebar navigation to complement the minimalist monochrome aesthetic.
- Grid-based structure with 32px of spacing between components, utilizing modular glassmorphism cards for content separation.
- Zero-latency UI transitions: fast 150ms fades for navigation and micro-interactions on table hover states.
